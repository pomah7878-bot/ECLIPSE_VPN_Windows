# Тестирование ECLIPSE VPN для Windows

## Чек-лист перед релизом

### 1. Установка
- [ ] Установщик запускается без ошибок
- [ ] При отсутствии VC++ Redistributable показывается предупреждение
- [ ] Приложение появляется в меню Пуск
- [ ] Ярлык на рабочем столе (если выбран)
- [ ] Автозапуск работает (если выбран)

### 2. Первый запуск
- [ ] Приложение запускается с правами администратора
- [ ] Окно открывается корректно (400x600)
- [ ] Нет ошибок в консоли (если запущено с --verbose)

### 3. Авторизация
- [ ] Вход по коду доступа работает
- [ ] Неверный код показывает ошибку
- [ ] OAuth Google открывает браузер
- [ ] OAuth Яндекс открывает браузер
- [ ] OAuth VK открывает браузер
- [ ] После OAuth возврат в приложение
- [ ] Сессия сохраняется после перезапуска

### 4. Ключи
- [ ] Список ключей загружается
- [ ] Отображаются сервер, протокол, срок
- [ ] Показ QR работает
- [ ] Копирование ссылки работает
- [ ] Кнопка "Импорт" добавляет ключ

### 5. VPN-подключение
- [ ] sing-box.exe запускается
- [ ] TUN-адаптер создаётся
- [ ] Подключение устанавливается за 2-3 секунды
- [ ] Статус меняется на "Подключено"
- [ ] Статистика трафика обновляется
- [ ] Отключение работает корректно
- [ ] Повторное подключение работает

### 6. Трей
- [ ] Иконка появляется в трее
- [ ] ЛКМ по иконке показывает/скрывает окно
- [ ] ПКМ открывает меню
- [ ] "Показать" работает
- [ ] "Выход" закрывает приложение

### 7. Фаервол
- [ ] Правило для eclipse_vpn_windows.exe создано
- [ ] Правило для sing-box.exe создано

### 8. Удаление
- [ ] Деинсталлятор запускается
- [ ] Все файлы удаляются
- [ ] Данные в %localappdata% удалены

## Тестовые сценарии

### Сценарий 1: Чистая установка
1. Удалить предыдущую версию
2. Установить из установщика
3. Запустить, войти по коду
4. Подключиться к VPN
5. Проверить IP (2ip.ru)

### Сценарий 2: Обновление
1. Установить старую версию
2. Войти, подключиться
3. Установить новую версию поверх
4. Проверить, что сессия сохранилась

### Сценарий 3: Ошибки сети
1. Отключить интернет
2. Запустить приложение
3. Проверить сообщение об ошибке
4. Включить интернет
5. Проверить восстановление

### Сценарий 4: Множественные ключи
1. Иметь 2+ активных ключа
2. Переключаться между ними
3. Подключаться к разным серверам

## Отладка

### Логи приложения
```
%LOCALAPPDATA%\ECLIPSE VPN\logs\
```

### Логи sing-box
Временный файл конфигурации:
```
%TEMP%\eclipse_vpn_config.json
```

Запуск sing-box вручную:
```powershell
.\sing-box.exe run -c %TEMP%\eclipse_vpn_config.json --disable-color
```

### Проверка TUN-адаптера
```powershell
Get-NetAdapter | Where-Object {$_.Name -like "*Eclipse*"}
```

### Проверка маршрутов
```powershell
route print | findstr "172.19"
```

## Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| "sing-box.exe не найден" | Проверить, что sing-box.exe в папке с приложением |
| Ошибка создания TUN | Запустить от имени администратора |
| Нет интернета после подключения | Проверить фаервол, добавить в исключения |
| Антивирус блокирует | Добавить папку приложения в исключения |
| Ошибка OAuth | Проверить, что порт 0.0.0.0 доступен |

## Минимальные требования

- Windows 10 1809+ (64-bit)
- 4 ГБ RAM
- 100 МБ свободного места
- Права администратора
