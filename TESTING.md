# Тестирование ECLIPSE VPN для Windows (v0.2.x)

## Автоматические проверки

```bash
flutter analyze --fatal-infos   # статический анализ — 0 замечаний
flutter test                    # unit-тесты парсеров ссылок и генератора конфига
```

Проверка конфига VPN без запуска (формат sing-box 1.11+):

```powershell
.\sing-box.exe check -c <путь к config.json>
```

## Тестовые сценарии

### Сценарий 1: Чистая установка
1. Удалить предыдущую версию
2. Установить из установщика
3. Войти по коду, подключиться
4. Проверить смену IP (2ip.ru) и режим «Умный»

### Сценарий 2: Перезапуск
1. Войти, подключиться
2. Закрыть приложение (крестик → трей), затем «Выход»
3. Запустить снова — сессия на месте, вход не требуется

### Сценарий 3: Ошибки сети
1. Отключить интернет, нажать «Подключить»
2. Убедиться в понятной ошибке и доступных логах
3. Включить интернет, подключиться снова

## Отладка

Логи видны в приложении: главный экран → «Показать логи»,
копирование — вкладка «Поддержка».

Файл конфига sing-box:
```
%APPDATA%\<org>\eclipse_vpn_windows\sing-box\config.json
```

Проверка TUN-адаптера:
```powershell
Get-NetAdapter | Where-Object {$_.Name -like "*Eclipse*"}
Get-NetAdapterStatistics -Name EclipseVPN
```

Проверка маршрутов:
```powershell
route print | findstr "172.19"
```

## Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| «sing-box.exe не найден» | Файл должен лежать рядом с приложением |
| «Нужны права администратора» | Перезапустить от имени администратора |
| Ошибка создания TUN | Проверить, что wintun.dll рядом с sing-box.exe |
| Rule-set не скачался | Нужен интернет при первом подключении |
| Антивирус блокирует | Добавить папку приложения в исключения |
